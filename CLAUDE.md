## What this project is

Black-box behavioral forensics: can simple behavioral signatures distinguish ordinary model errors (Arm 1: organic, no hint) from cue-driven errors (Arm 2: correct without hint, wrong with planted hint), without reading chain-of-thought? Key discriminator: cue-tracking. CoT-guided internals = stretch only, hours 12+, only if Khalid says so. The design is LOCKED. Do not propose redesigns; flag problems to Khalid instead.

## Engineering conventions

- One entrypoint: `src/run_grid.py` — takes question set + condition + n_samples, writes `results/*.jsonl`. Batch-first: scaling N is a config change.
- Conditions: no_hint, hint@option, paraphrase_k, self_report_probe. Hint texts live in `data/hints/` as config, never hardcoded.
- Deterministic seeds. Resumable runs. Every raw completion saved with full prompt, timestamp, sampling params. Nothing in `results/` is ever deleted or overwritten.
- Metrics only in `src/metrics.py`, each with a docstring definition and a unit test on toy data. Headline numbers get a second, independent derivation path.
- Figures generated by script from results files; labeled axes; N in every caption.
- Long jobs: background scripts with checkpoints. Analysis: persistent Jupyter kernel (notebooks/), never re-run expensive cells.
- Model: current-generation reasoning model only (Qwen 3.x dense thinking variant primary, current Gemma fallback). Older generations (GPT-2, Pythia, Gemma 2) are not used.
